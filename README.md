
Proyecto sencillo de parcel

Tener Node.js y npm instalados. npm se instala junto con node

- npm create parcel vanilla my-parcel-app --> crea un proyecto nuevo de Parcel con la plantilla 
- npm start --> inicia el servidor de desarrollo del proyecto
- npm install --save-dev parcel --> instala Parcel 
- npx parcel src/index.html --> inicia Parcel usando `src/index.html` como parametro

Al ejecutar el servidor, abriendo `http://localhost:1234/`  se deberia ver la pagina
